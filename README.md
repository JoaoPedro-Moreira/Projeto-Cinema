# Projeto Cinema

## Sobre o projeto

Projeto acadêmico desenvolvido em Java que consiste em um sistema de gerenciamento de cinema, aplicando conceitos de Programação Orientada a Objetos.

A aplicação foi criada para praticar a organização de classes e objetos na construção de um sistema.

## Objetivo

Desenvolver a lógica de programação e aprofundar os conhecimentos em Programação Orientada a Objetos, trabalhando a estruturação e a interação entre classes.

## Tecnologias

- Java
- Programação Orientada a Objetos (POO)

## Funcionalidades

O projeto implementa um sistema de gerenciamento de cinema. Suas funcionalidades específicas devem ser descritas conforme as operações disponíveis no código.

## Como executar

1. Clone o repositório:

   ```bash
   git clone COLE_AQUI_A_URL_DO_REPOSITORIO
   ```

2. Abra o projeto em uma IDE compatível com Java.
3. Configure o JDK no ambiente.
4. Localize a classe principal que contém o método `main`.
5. Execute a aplicação.
